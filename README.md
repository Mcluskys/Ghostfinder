# Memory des Fantômes 👻

Petit jeu de Memory en HTML/CSS/JavaScript, pensé pour fonctionner sur :

- smartphone
- tablette
- PC / Mac

Aucune installation ni bibliothèque externe n'est nécessaire.

## Jouer

Retournez deux cartes. Si les symboles sont identiques, la paire reste visible.
Retrouvez toutes les paires avec le moins de coups possible.

Trois niveaux sont disponibles :

- Facile : 6 paires
- Moyen : 8 paires
- Difficile : 10 paires

## Publier sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Ajoutez `index.html`, `style.css` et `game.js` à la racine du dépôt.
3. Faites un commit puis un push.
4. Sur GitHub, ouvrez `Settings` → `Pages`.
5. Dans `Build and deployment`, choisissez `Deploy from a branch`.
6. Sélectionnez la branche `main` et le dossier `/ (root)`.
7. Enregistrez.

GitHub vous donnera ensuite l'adresse publique du jeu.

## Compatibilité

Le jeu utilise uniquement des technologies web standards :
HTML5, CSS responsive et JavaScript vanilla.

Il est jouable au clic, au toucher et au clavier.


## Affichage plein écran

Le plateau se redimensionne automatiquement pour que toutes les cartes restent visibles sans défilement sur smartphone, tablette et ordinateur. L'interface s'adapte aussi aux petits écrans et au mode paysage.
